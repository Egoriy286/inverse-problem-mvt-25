# Окружения

## Базовое окружение

Базовая среда описана в `pyproject.toml` и покрывает NumPy/SciPy, Matplotlib,
Pillow, Jupyter и tqdm. Она используется для лабораторных 1–5, общих утилит и
тестов.

```bash
uv sync --extra dev
uv run pytest
```

## FEniCS/dolfin

Лабораторные 6–8 содержат варианты на `dolfin`. Этот пакет не включён в
обязательные зависимости: его доступность зависит от версии Python, ОС и
способа установки FEniCS.

Для запуска этих работ нужно создать отдельное окружение по инструкции,
соответствующей установленной версии FEniCS, затем запускать скрипты из
корня репозитория. Результаты направляются в `results/lab06`, `results/lab07`
или `results/lab08`, как указано в скриптах.

Если `dolfin` недоступен, это не блокирует установку базового окружения,
тесты общего кода и лабораторные на чистом NumPy/SciPy.
