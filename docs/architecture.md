# Архитектура репозитория

Репозиторий разделён по смыслу предметной области, а не только по расширениям
файлов.

```text
src/inverse_problems/     общий проверяемый код
labs/master/              учебные лабораторные текущего курса
education/bachelor/       исторические учебные материалы
experiments/              самостоятельные исследовательские запуски
configs/                  параметры воспроизводимых запусков
data/raw                  исходные данные
data/processed            производные данные
results/                  графики и вычисленные результаты
references/               методички и книги
archive/legacy            материалы без безопасной классификации
```

Алгоритм, используемый несколькими лабораторными, может быть вынесен в
`src/inverse_problems`. Постановка конкретной задачи, параметры тестового
примера и визуализация остаются рядом с экспериментом, пока между ними нет
устойчивого общего интерфейса.

Результат должен быть связан с исходным кодом, конфигурацией, данными и
командой запуска. Поэтому новые эксперименты обязаны иметь локальный README и
не должны записывать файлы в корень репозитория.
