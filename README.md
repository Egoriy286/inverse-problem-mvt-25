## Лабораторная работа №2 (`laba2/`)

Решение обратной задачи определения коэффициента v(t) в уравнении переноса-диффузии.

### Постановка задачи

Найти функции `u(x,t)` и `v(t)`, удовлетворяющие уравнению:

```
∂u/∂t = ∂²u/∂x² - v(t)·∂u/∂x,  x∈(0,l), t∈(0,t̄]
```

с граничными и начальными условиями:
```
u(0,t) = μ₁(t),  u(l,t) = μ₂(t)
u(x,0) = u₀(x)
```

и дополнительным условием переопределения:
```
∫₀ˡ u(x,t) dx = φ(t)
```

### Файлы

| Файл | Описание |
|------|----------|
| `lab2.py` | Основная реализация метода |
| `lab2codex.py` | Альтернативная реализация |
| `lecture2.md` | Теоретическое описание разностной схемы |

### Численный метод

Используется разностная схема с линеаризацией:

1. **Дискретизация:**
   - `xᵢ = ih, i = 0..N, h = l/N`
   - `tⱼ = jτ, j = 0..J, τ = t̄/J`

2. **Линеаризация:**
   ```
   yᵢʲ⁺¹ = zᵢʲ⁺¹ + vʲ⁺¹·wᵢʲ⁺¹
   ```

3. **Восстановление vʲ⁺¹:**
   ```
   vʲ⁺¹ = [φʲ⁺¹ - Σ(h/2)(zᵢʲ⁺¹ + zᵢ₋₁ʲ⁺¹)] / [Σ(h/2)(wᵢʲ⁺¹ + wᵢ₋₁ʲ⁺¹)]
   ```
